# 接口发布交接记录

复制到负责当前交付的工程 `docs/releases/<能力ID>/<版本>.md` 或已有交付目录。上游任务先填写上游部分，接入任务链接该记录并补全客户部分，文档任务补全文档部分。不同仓库可以各保存自己的记录并相互链接，不靠聊天记忆衔接。

这是内部交接记录，不列入 `public-docs.json`，不自动发布到客户站。不要填写真实 Key、Token、账户隐私或渠道密钥。未知项写“待验证”，不填推测值；不适用项说明原因。
