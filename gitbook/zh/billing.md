# 计费

账户余额、分组倍率、模型权限和消费记录以[控制台](https://openai.2yanx.dpdns.org)当前配置为准。

| 能力 | 计费方式 | 说明 |
| --- | --- | --- |
| 图片 | 按成功图片张数和分辨率档位 | 每请求一张；Lite 仅开放 1K；具体价格见控制台 |
| 视频 | 按成功视频条数 | 每请求一条；当前公开价格和模型限制见视频指南 |

当前视频价格不随时长、分辨率或生成模式额外乘算。其他分组按实际分组倍率结算。视频提交时预扣，失败后退款；参数校验失败不扣费。详细说明见[视频指南](guides/media-video.md)。

图片完成事件不提供原厂 token 使用量；缺少 `usage` 不代表没有计费。不能将按张收费理解成按文本 token 收费。

## 超时与交付

客户端收到超时、502/504 或断开连接时，后台任务可能继续执行并成功收费。先保存任务 ID 或图片请求 ID，查询原任务与消费记录。不要仅凭客户端没有拿到产物就重新发起生成。
