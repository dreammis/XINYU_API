## 计费根因与修正

首次短、长同步均返回正确 MP3，但日志17265、17271的结算费用为0。`service/quota.go` 中音频结算的旧按次路径没有按 ModelPrice 正确结算；仅检查价格配置或账户总差值会误判（同时存在异步扣费）。

复用 B 已有表达式定价，读取当前完整配置后只合并本次条目：

```json
{
  "billing_setting.billing_mode": {"vox-1": "tiered_expr"},
  "billing_setting.billing_expr": {"vox-1": "tier(\"request\", fixed(0.01369863))"},
  "billing_setting.plugin_billing_expr": {"media-tts::vox-1": "tier(\"request\", 0.01369863)"}
}
```

上例只展示本次条目，不能整份覆盖全局配置。任务表达式使用 USD 任务语义，不能使用原生 HTTP 的 fixed()；先保存插件专用表达式，再保存模型表达式与启用模式。原 ModelPrice 保留用于回退，其他模型条目保留。默认分组1、USDExchangeRate7.3、QuotaPerUnit500000，每成功生成6849 quota，约¥0.10。

## 发布边界

1.1.0公开契约以同步为首入口，保留异步查询和鉴权产物下载；支持353音色、24语言。Vox 1不支持SSE，不能把任务状态或MP3下载伪装成生成流。

实际短长成功耗时不是最大延迟承诺。未人为制造供应商执行失败、断连或超时；不能承诺同步断连后的具体结算。A的生成可能继续，B不提供同步客户任务ID，公开指南明确禁止自动重发；需要持久查询时使用异步。输入失败实测费用0；历史异步生成失败退款证据见1.0.0。同步详细错误被B转成通用错误，此项已如实写入指南。

回退同步可禁用渠道25；不动渠道24和旧任务。表达式回退需同时考虑插件覆盖与模型模式，使用修改前当前值，仅恢复本次条目；旧音频 ModelPrice 路径有零费用问题，不能作为收费正常的同步回退方案。
