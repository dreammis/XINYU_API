# 常见问题

## 模型名称和原厂模型一样吗？

文档列出的是本站公开调用名称。名称不构成原厂直连或精确模型快照保证。先查看[模型中心](models.md)和对应能力指南，再根据实际限制选择。

## 为什么返回 401 或 403？

检查是否使用客户 API Key，是否具有目标模型权限，以及账户限制。控制台管理令牌不能代替生成密钥。见[鉴权](authentication.md)。

## 在线调试会扣费吗？

会。调试调用真实客户接口，生成请求按正常规则计费。查询、失败和退款行为见[计费](billing.md)。调试中的 Key 只用于当前页面，不持久保存。

## 请求超时，能立即重试吗？

超时或断连不能证明后台停止。先查询原任务和消费记录，确认结果后再决定是否重新提交，避免重复生成和计费。见[错误与任务恢复](errors.md)。

## HTTP 200 或任务 ID 就代表生成成功吗？

图片流式调用要收到完成事件；视频创建返回任务 ID 后仍需查询，状态为 `completed` 时下载文件。状态查询不是文件下载，详见对应能力指南。

## 为什么看不到 TTS、音乐等接口？

正式接口目录只展示已有公开契约的能力。未发布的系列会在概览标明状态，正式交付后进入对应系列。
